# 🌸 کارت دعوت دیجیتال عروسی (نسخه فارسی)

پروژه وب‌سایت کارت دعوت هوشمند و لوکس عروسی با برنامه‌نویسی React 19، Vite، Tailwind CSS و انیمیشن‌های فانتزی GSAP & Lenis به همراه پشتیبانی کامل از زبان فارسی و راست‌چین (RTL).

## 🚀 ویژگی‌های اصلی

- **تنظیمات متمرکز و هوشمند (`src/config/invitation.config.ts`)**: امکان تغییر سریع نام‌های عروس و داماد، تاریخ، ساعت، متن‌های دعوت، آدرس تالار، نقشه گوگل، عکس‌ها و ویدیوها بدون دست زدن به کدهای اصلی.
- **تایپوگرافی اصیل فارسی**: استفاده از فونت‌های استاندارد وزیرمتن (Vazirmatn) و امیری (Amiri).
- **روزشماری هوشمند (Countdown)**: نمایش روزشماری تا تاریخ برگزاری عروسی با اعداد فارسی.
- **گالری تصاویر پویا**: نمایش عکس‌های خاطره‌انگیز با جلوه‌های تصویری و هاورهای جذاب.
- **نمایش ویدیو دعوتنامه**: پخش آنلاین تیزر یا کلیپ دعوت عروسی.
- **مسیریابی هوشمند (Location)**: نقشه گوگل تعاملی به همراه لینک‌های مستقیم مسیریابی در Google Maps، نشان و بلد.
- **فرم اعلام حضور آنلاین (RSVP)**: فرم تعاملی جهت دریافت وضعیت حضور مهمانان با پشتیبانی از گوگل شیت (Google Sheets API).

## 🛠️ راهنمای شخصی‌سازی (تغییر عکس، ویدیو، آدرس و تاریخ)

برای تغییر اطلاعات عروسی، تنها کافیست فایل زیر را ویرایش کنید:
`src/config/invitation.config.ts`

```typescript
export const invitationConfig = {
  groomName: "حمید",
  brideName: "فاطمه",
  welcomeText: "با کمال مسرت و شادمانی شما را به جشن پیوند آسمانی‌مان دعوت می‌نماییم",
  gregorianDate: "2026-08-13T18:00:00", // تاریخ جهت روزشمار
  persianDateText: "پنج‌شنبه ۲۲ مرداد ۱۴۰۵ - ساعت ۱۸:۰۰",
  venueName: "تالار پذیرایی شهدخت",
  venueAddress: "تهران، احمدآباد مستوفی، خیابان صنوبر",
  googleMapsEmbedUrl: "...", // لینک Iframe گوگل مپ
  googleMapsDirectUrl: "...", // لینک مستقیم گوگل مپ
  videos: {
    heroBg: "/sub.mp4",       // ویدیو پس‌زمینه اصلی
    heroPoster: "/poster.jpg", // عکس کاور ویدیو
  },
  images: {
    gallery: [ ... ]          // عکس‌های گالری
  }
};
```

فایل‌های رسانه‌ای (عکس‌ها و ویدیوها) را می‌توانید در پوشه‌های `public/` یا `public/images/` قرار داده و مسیر آن‌ها را در کانفیگ فوق ثبت کنید.

## 💻 راهنمای اجرا و نصب

```bash
# ۱. نصب پیش‌نیازها
npm install

# ۲. اجرای سرور توسعه
npm run dev

# ۳. خروجی نهایی جهت آپلود روی هاست
npm run build
```
